## Builded a Rock Paper Scissors Game using Tkinter & Python

A simple GUI Rock–Paper–Scissors game built with Python and Tkinter. Choose Rock, Paper, or Scissors and play against the computer which makes random choices.

Features:
- Clean Tkinter-based interface
- Score tracking for player and computer
- Simple game logic with win/lose/draw outcomes

Requirements:
- Python 3.7+
- tkinter (usually included with standard Python installs)

How to run:
1. Open a terminal in the project directory.
2. Run: python rps.py
3. Click a button (Rock, Paper, or Scissors) to play a round.

License / Notes:

- Feel free to extend with animations, sound, or persistent scoring.
