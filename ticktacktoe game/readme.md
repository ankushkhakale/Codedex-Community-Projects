
# Tic-Tac-Toe (CLI)

Simple two-player command-line Tic‑Tac‑Toe using `prompt-sync` for input. Players take turns entering a position 0–8 to place their mark.

Requirements
- Node.js
- `prompt-sync` (install with `npm install prompt-sync` inside the game folder)

Run
```
cd "C:\Users\khaka\OneDrive\Documents\Codedex Community Projects\ticktacktoe game"
node tictactoe.js
```

Board positions
```
0 | 1 | 2
---------
3 | 4 | 5
---------
6 | 7 | 8
```

Controls
- Enter a number 0–8 when prompted to place your mark.

Notes
- Players in the script use emoji marks (e.g. `🐐` and `🍇`).
- If the program exits immediately or shows no prompt, run `npm install prompt-sync` and try again.
