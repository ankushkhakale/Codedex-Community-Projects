
# Pong Game

Simple two-player Pong clone built with Pygame.

Requirements
- Python 3.7+
- `pygame` (install with `pip install pygame`)

Run
```
python game.py
```

Controls
- **Player 1:** `W` (up), `S` (down)
- **Player 2:** `Up Arrow` (up), `Down Arrow` (down)
- **Start:** `Space` (press to begin)
- **Quit:** close the game window

Notes
- Window size: 960×720
- The game file is `game.py`.
